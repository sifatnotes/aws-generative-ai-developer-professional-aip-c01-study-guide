## Exam Overview

The **AWS Certified Generative AI Developer - Professional** exam validates advanced technical expertise in designing, building, deploying, and optimizing enterprise-grade Generative AI applications on AWS.

| Parameter | Exam Specification |
| --- | --- |
| **Official Exam Name** | AWS Certified Generative AI Developer - Professional |
| **Exam Code** | `AIP-C01` (also cataloged as `AIF-P01`) |
| **Total Questions** | 65 scored questions (+ 10 unscored pretest questions) |
| **Time Allowed** | 180 Minutes |
| **Passing Score** | 750 / 1000 (Scaled score) |
| **Delivery Method** | Pearson VUE (Online Proctored via OnVUE or Test Center) |
| **Prerequisites** | 2+ years building production applications on AWS; 1+ year hands-on GenAI experience |
| **Validity** | 3 Years |

---

## Who Should Take It

This exam is designed for Senior Software Engineers, Cloud Architects, AI/ML Developers, and Solutions Architects responsible for building, optimizing, and securing enterprise GenAI solutions on AWS.
